# 🎵 TuneBox – Box| HTML

## 📌 Project Description

TuneBox is a music playlist web interface developed using **HTML5**. The project provides a clean and structured layout for displaying songs and managing playlist-related sections.

The HTML page is designed with a clear separation of different UI components such as the **header, playlist section, song cards, playlist controls, recently added songs, playlist summary, and footer**.

The project focuses on creating a well-organized and reusable **HTML structure** that can be enhanced with CSS for styling and JavaScript for dynamic functionality.

## ✨ Key Features

- 🎵 Displays songs with title, artist, and genre
- 🎧 Individual song cards with playlist buttons
- 🎛️ Playlist Controls section
- 🕒 Recently Added songs section
- 📊 Playlist Summary section
- 📱 Clean and structured webpage layout
- 🧩 Semantic and organized HTML structure

## 🛠️ Technology Used

- HTML5
